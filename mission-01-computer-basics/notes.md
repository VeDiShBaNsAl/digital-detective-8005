# Mission 1 - Computer Fundamentals and IPOS Notes

## Task 1.1: Trace one activity using IPOS (Saving a Document)
| Stage | What happens in your example? | Possible hardware/component |
| :--- | :--- | :--- |
| **Input** | Typing text using the keyboard and clicking the save button with the mouse. | Keyboard, mouse, camera or microphone |
| **Processing** | The CPU interprets keystrokes and system instructions while data is held temporarily in memory. | CPU/processor and memory |
| **Output** | Displaying the visual text on the screen and showing the save confirmation message. | Screen, speaker or printer |
| **Storage** | Writing and saving the file permanently onto the drive. | SSD, hard disk or cloud storage |
