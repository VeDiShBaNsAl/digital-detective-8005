# Mission 2 - Terminal and File Management Notes

## Task 2.1: Explore basic Terminal operations
| Operation / command name | What it does | What I observed |
| :--- | :--- | :--- |
| **Current-directory display** (`pwd`) | Outputs the full absolute path of the directory you are currently working in. | Prints the full folder path starting from the root system. |
| **Directory listing** (`ls`) | Lists all visible files and folders contained in your current working location. | Shows a plain horizontal list of files and folder names. |
| **Detailed listing** (`ls -la` or `ls -l`) | Displays files and folders in a detailed format, including permissions, file sizes, and timestamps. | Shows vertical rows with permissions, file sizes, modification dates, and names. |
| **Change directory** (`cd ..`) | Moves your working location to the parent folder. | The terminal prompt path updates to show you are now one level higher up. |
| **Create directory** (`mkdir`) | Creates a brand new folder in your current location. | A new folder appears silently in the directory without outputting any text. |
| **Create empty file** (`touch`) | Creates a new, blank file inside the target location. | An empty file is generated instantly in the specified path. |
| **Copy file** (`cp`) | Makes an exact duplicate of a file under a new name or destination. | A duplicate file appears alongside the original. |
| **Move / rename file** (`mv`) | Relocates or renames an existing file or folder. | The file is renamed or moved to the new specified destination. |
| **Display file contents** (`cat`) | Prints the internal text or data of a file directly onto the terminal screen. | The text written inside the file is displayed line-by-line in the terminal window. |

## Task 2.2 — Practise file changes safely

### Questions & Answers:
* **What is the difference between replacing a file's contents and adding text to the end?**
  Replacing a file's contents (using a single `>`) overwrites any existing data entirely, clearing out old text. Adding text to the end (using the append operator `>>`) preserves all existing data and appends the new text as a new line at the bottom.

* **What is the difference between copying a file and moving a file?**
  Copying (`cp`) duplicates the file, leaving the original intact while creating an identical copy in the destination. Moving (`mv`) relocates or renames the original file itself, meaning it no longer exists in its original location or name.

* **What information does the current-directory display provide?**
  It provides the absolute path starting from the system root down to your current working location, letting you know precisely where you are situated in the filesystem hierarchy.

* **Why is a directory-listing operation useful?**
  It allows you to inspect what files and subfolders are available in your current location so you can verify file creation, check filenames, and navigate effectively.

## Task 2.3 — Understand flags and pipes

### Questions & Explanations:
* **What changes when you add flags to the `ls` command?**
  Running a plain `ls` only shows visible files and folders in a simple horizontal layout. Adding flags modifies the behavior:
  * `-l` provides a detailed vertical layout including permissions, owner details, timestamps, and file sizes.
  * `-a` unmasks hidden system files (such as `.git`).
  * `-h` converts raw byte sizes into human-readable units (e.g., KB, MB). Combining them into `ls -lah` gives a comprehensive, detailed view of everything in the folder.

* **What does the pipe symbol (`|`) do and what does each side contribute?**
  The pipe symbol (`|`) takes the standard output generated by the command on its **left side** and passes it directly as the standard input into the command on its **right side**.
  * **Left side (`ls -lah`):** Generates the full detailed directory listing.
  * **Right side (`head -n 5`):** Receives that list as input and filters it to display only the first 5 lines, preventing terminal clutter when dealing with massive directories.

## Task 2.4 — Understand package managers

### Notes & Answers:
- **Why package managers are useful:**
  Package managers automate the process of installing, updating, configuring, and removing software applications safely from a centralized repository. Instead of manually searching for software installers online, dealing with broken links, or tracking dependency updates by hand, a package manager handles everything via simple command-line instructions while ensuring system stability.

- **What a package manager does:**
  It acts as an automated software assistant that retrieves applications, verifies digital signatures or dependencies, installs them into the correct system directories, and manages future updates or uninstalls seamlessly.
- **What a package manager does (Homebrew not installed):**
  A package manager acts as a centralized, automated software store and installer for the command-line environment. Instead of manually downloading software packages from various websites, handling installer wizards, and updating applications individually, a package manager automatically fetches, installs, configures, and updates software and its underlying dependencies from a secure repository with a single terminal command.
